# Job-description traceability matrix

**Assumption:** the job-description text itself was not supplied with the brief; the requirement rows below are the capabilities the brief lists for the Senior Software Engineer role (Java, API management and observability, distributed systems, containers/Kubernetes/cloud, security, AI-assisted development, leadership). If your copy of the JD differs, add rows - the evidence columns show how to map.
**Evidence rule:** a capability counts as *demonstrated* only when it points to code, a test, a script or *clearly labelled conceptual material*. "Validated" means a command was run (see `docs/validation/validation-report.md`).
